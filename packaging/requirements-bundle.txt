# What the downloadable bundles are built from (packaging/build.py, .github/workflows/bundles.yml): the app's
# requirements (pyproject.toml) at the versions the Linux x86_64 bundle was built and smoke-tested with on 2026-11-08
# (Python 3.14, docs/packaging.md), plus the optional extras the bundles carry (dexvantage/extras.py: lerobot, bags,
# assistant) and the small validation references. Change a pin only together with a build whose smoke test passes.
#
#   python -m pip install -r packaging/requirements-bundle.txt
#
# Not for running from source (pip install -e ".[lerobot,bags,assistant]" there): this file takes
# opencv-python-headless in place of opencv-python (no OpenCV GUI and no second copy of Qt in the bundle), so the two
# must not be installed into the same environment.
#
# Linux arm64 (NVIDIA Jetson with JetPack 6 = Ubuntu 22.04, glibc 2.35): PyQt6's and Qt's aarch64 wheels from 6.8 on
# are manylinux_2_39 (glibc 2.39, Ubuntu 24.04) and will not install there; 6.7.1 / 6.7.3 are the newest built for
# manylinux_2_28 (PyPI, read 2026-11-08). Every other platform takes 6.12.0. DexVantage declares PyQt6>=6.5 but has
# been tested on 6.12 only: the arm64 CI job's self-test is the check for 6.7.
